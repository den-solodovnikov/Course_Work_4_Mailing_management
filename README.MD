Проект 4. Сервис управления рассылками
Описание:
Проект "Сервис управления рассылками" - это веб-приложение на Django, 
которое позволяет пользователям управлять рассылками сообщений для клиентов.

Установка:
Установите на свой компьютер GitHub.
Клонируйте репозиторий с GitHub с помощью веб-URL.
 git clone git@github.com:den-solodovnikov/HomeWork_22.git
